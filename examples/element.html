<umlimator-map>

A map from HTML alone: <umlimator-map src="bookshop.json"> loads the model and draws it. Its still shows until then, and stays where scripts don't run. Each control below sets an attribute, and the map follows.

A model in the page

No file to fetch: the model sits in a <script type="application/json"> inside the element, next to a sentence for where scripts don't run.

The web shop calls the shop API, which writes orders to its database.

In a docs site

A fenced block becomes this element: umlimator/markdown-it for VitePress, umlimator/remark for Docusaurus. A block names a model's src, or holds the model in JSON; on MkDocs, or any site that allows HTML, write the element itself. The README's Embed section has each setup.

```umlimator
src: /maps/bookshop.json
view: api
```
