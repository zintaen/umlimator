A class diagram editor

Select a class to edit it in the properties panel: its name, stereotypes, and each member as one line of UML (+ total: Money [1] = 0, + place(at: Date): Order). A palette entry, or N: add a class · drag a selected class's handle to another, or L: add a line, then pick its kind · F2: rename · Alt + arrows: pin it elsewhere · Delete: remove from this view, with Shift: from the model · ⌘/Ctrl + Z: undo, with Shift: redo.
