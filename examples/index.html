In an app

PlaygroundEdit a model and see the map, its problems (validate()), its broken rules (rules()) and its layout check (check()); share it by link.
Card shapesThe card shapes model, light and dark: all 13 shapes, and a card's own shape.
The element<umlimator-map src="…">: a map from HTML alone, its still shown until it is drawn; the block a docs site (VitePress, Docusaurus, MkDocs) turns into it.
A host pagerender() with the standalone page's pieces (views list, details panel, legend, hint line), views loaded when opened, SVG and PNG export, themes and the minimap.
Live trafficoverlay() every second: flow as fast as the traffic, errors that pulse, slow lines that glow, lag on each card; the model never changes.
Ask the mapQuestions answered with words, the paths or reach they are about lit, and a tour; the view in sentences (describe()) for an AI model.
Trace replayAn OpenTelemetry trace played on the map: each call along its line at its time, with its duration.
EditingThe map emits change events; the host applies them and keeps an undo history.
A class diagram editorA class diagram emits edit events, each a transaction of commands; the host applies them with apply() and keeps history() for undo and redo.
A time-lapseFour releases on a slider: new cards fade in, removed ones fade out, moved ones glide; diff() says what changed.
Drawn vs. seendrift(): the map against a week of traffic; lines that ran undrawn come in, idle ones fade.
In Nodelayout() without a browser, as a check a host can run in CI on maps it generates.
