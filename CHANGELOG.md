# Changelog

Each release's changes are in [docs/module-api.md](docs/module-api.md), one `## X.Y.Z: …` section per version, newest
last. The same section is that version's [GitHub Release](https://github.com/zintaen/umlimator/releases) notes, and the
documentation site shows the file as its [Changelog](https://zintaen.github.io/umlimator/changelog.html).
