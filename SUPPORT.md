# Getting help

- Read the [documentation](https://zintaen.github.io/umlimator/): the guide covers the model, embedding, editing, the CLI, the GitHub Action, the MCP server, import and icon packs, and the API reference lists every export.
- Try a model in the [playground](https://zintaen.github.io/umlimator/examples/playground.html), or start from one of the [examples](https://zintaen.github.io/umlimator/examples.html).
- Ask a question or share an idea in [GitHub Discussions](https://github.com/zintaen/umlimator/discussions).
- Report a bug or request a feature with an [issue](https://github.com/zintaen/umlimator/issues/new/choose). A small model that shows the problem gets it fixed fastest.
- Report a security problem privately, as [SECURITY.md](SECURITY.md) says, never in a public issue.
